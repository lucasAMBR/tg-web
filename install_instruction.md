# Guia de instalacao

## Requisitos

* Node: 25.6
* NPM: 11.8

# Passo a Passo

1 - Instale  globalmente o pnmp com o comando: npm install -g pnpm

2 - Instale as dependencias do projeto com: pnpm install

3 - Para executar o projeto, garanta que api esta correta e na porta especificada no .env, e de o comando: pnpm dev
